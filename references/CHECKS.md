# 办理中的资料检查

只有确实影响办理时才使用本说明。正常流程不展示隐藏字段，不请员工核对后台主管、行政联系人、内部归属或编码；原规则允许为空且不影响办理时直接继续。

| 实际问题 | 处理 |
| --- | --- |
| 员工应提供的日期、事由、金额或文件缺失 | 合并询问对应业务信息，修改同一草稿。 |
| 必需组织、主管、任职、假勤资料缺失或不唯一 | 简短说明需要 HR 核查，不能让员工手填主管ID或内部字段。 |
| 必需业务归属、币种、科目、供应商等财务配置缺失或不唯一 | 请 Finance 核查，不能猜值或把系统维护转嫁成选编码。 |
| 登录、权限、接口、版本、格式故障或无法明确分类 | 请 IT 核查；不要反复登录或修改脚本绕过。 |

不能凭“字段像审批人”新增必填，也不能把HTTP失败当成正常可空。是否阻断以本流程已核对的业务规则和当前必填要求为准。成功返回空目录与明确拒绝访问是不同的问题。

可空隐藏字段不加第二次确认。最终只确认一次用户业务预览；操作不成功与内容回读暂未核验分开，任何结果未知都不自动重试写操作。详细支持信息见 [DEBUG](DEBUG.md)。
